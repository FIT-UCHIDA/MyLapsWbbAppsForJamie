## 4. 「Webを直したらDesktopも直す」運用ルール

### 4.1 修正の流れ

```
1. Web版を修正・テスト
2. 対応表（§2）で 🔴 を ✅ に更新
3. 同じ修正をDesktop版の対応関数に適用
4. デスクトップアプリで動作確認
5. 両方コミット（同一コミットメッセージに "[Web+Desktop]" を付ける）
```

### 4.2 長期的改善案：shared_kpi パッケージ化

```
20260430_MyLapsWebApps/
├── shared_kpi/              ← 共通ライブラリ（新規作成）
│   ├── __init__.py
│   ├── db.py               ← get_df_from_db, jst_str_to_utc_sql, to_jst_naive
│   ├── decoders.py         ← translate_dict, TRACK_ORDER
│   ├── lap_split.py        ← split_laps, fetch_df_from_db
│   └── kpi_calc.py         ← ensure_interval_columns, display_kpi_columns
├── webapp/
│   └── utils.py            ← from shared_kpi import * + Web固有追加
└── 20260701_DesktopApp/
    └── utils.py            ← from shared_kpi import * + Desktop固有追加
```

この構成にすれば「shared_kpi を直す = 両方に反映」が実現できる。  
ただし既存のimport構造を変える必要があるため、段階的に移行する。  
**今回のPhase 1/2はコピーベースで対応し、shared化はPhase 3として別タスクにする。**
