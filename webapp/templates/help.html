Help / Usage Guide

  1. Open the app URL in your browser.
  2. Select your user profile from the dropdown (or leave it blank for global settings).
  3. Enter the password and click Login.
  4. You can switch users later via Switch User in the navbar.

  1. Date Range: Set start/end datetime on the main page, then click Fetch Players.
  2. Player Selection: Check the players you want, then click Show KPI.
  3. Mode: Switch between modes (e.g., "stand", "roll") using the Mode dropdown.
  4. Show All Columns: Toggles display of all data columns (including raw timing data).
  5. Show All Data: Shows data rows not filtered by mainKPI criteria.
  6. Max Rows: Limits the number of rows per player.
  7. Export to CSV: Downloads the current table as a CSV file.
  8. Copy Selected (TSV): Click rows to select (Ctrl+click for multiple), then click this button or press Ctrl+C to copy as tab-separated values.
  9. Filter: Choose a column, set Min/Max, and click Apply Filter to narrow results.
  10. Update to Latest (Ctrl+R): Refreshes the data from the database.

Two editing methods are available:

Visual Editor (Edit KPI Setting button on KPI page)
  • Add/remove modes and intervals using the GUI.
  • Set mainKPI and sortOrder for each mode.
  • Changes are saved with the Save button.
JSON Text Editor (KPI Settings in navbar)
  • Directly edit the raw JSON text of your kpi.json file.
  • Validate: Checks JSON syntax before saving.
  • Format: Auto-formats (pretty-prints) the JSON.
  • Save (Ctrl+S): Validates and saves.
  • Upload: Upload a .json file from your computer.

If you have a KPI configuration from the old desktop application:

  1. Open the old app's kpi.json file in a text editor.
  2. Copy the entire JSON content.
  3. Go to KPI Settings in the navbar.
  4. Clear the text area and paste the copied JSON.
  5. Click Validate to check for errors.
  6. Click Save.

Alternatively, use the Upload button to directly upload the .json file.

JSON Structure Reference
{
  "settings": {
    "showAllColumns": true,
    "showAllData": false,
    "maxRows": 5
  },
  "stand": {
    "intervals": [
      {"start": "FP_start", "end": "0m_start", "label": "Time000to625"},
      {"start": "0m_start", "end": "100m", "label": "Time000to100"}
    ],
    "mainKPI": "Time000to100",
    "sortOrder": "asc"
  }
}

  • Every time you save or upload a KPI/settings file, a timestamped backup is automatically created.
  • Backups are stored in a backups/ subfolder next to the original file.
  • Backup filenames include the date and time: kpi_20260522_170300.json
  • Up to 50 backups are kept per file. Older backups are automatically deleted.
  • If you need to restore a previous version, contact your administrator.

  • Admin Login: Click "Admin" in the navbar and enter the admin password.
  • Add User: Enter a username and click Add. A new profile is created with a copy of the global settings.
  • Enable/Disable: Toggle user accounts on/off without deleting them.
  • Edit JSON: Directly edit a user's settings.json or kpi.json.
  • KPI Overview: View all users' KPI configurations at a glance.
  • Delete User: Permanently removes the user and all their settings.

  1. ブラウザでアプリのURLを開きます。
  2. ドロップダウンからユーザープロファイルを選択します（空白の場合はグローバル設定を使用）。
  3. パスワードを入力して Login をクリックします。
  4. ナビバーの Switch User から後でユーザーを切り替えることもできます。

  1. 日付範囲：メインページで開始/終了日時を設定し、Fetch Players をクリックします。
  2. 選手選択：表示したい選手にチェックを入れ、Show KPI をクリックします。
  3. モード：ドロップダウンでモード（例："stand", "roll"）を切り替えます。

  5. Show All Data：mainKPI基準でフィルタリングされないデータ行も表示します。
  6. Max Rows：選手ごとの表示行数を制限します。
  7. Export to CSV：現在のテーブルをCSVファイルとしてダウンロードします。
  8. Copy Selected (TSV)：行をクリックして選択（Ctrl+クリックで複数選択）、ボタンまたはCtrl+Cでタブ区切りでコピーします。

  10. Update to Latest（Ctrl+R）：データベースから最新データを再取得します。

2つの編集方法があります：

ビジュアルエディタ（KPIページの「Edit KPI Setting」ボタン）
  • GUIでモードや区間を追加・削除できます。
  • 各モードの mainKPI と sortOrder を設定できます。
  • Save ボタンで変更を保存します。
JSONテキストエディタ（ナビバーの「KPI Settings」）
  • kpi.jsonファイルの生のJSONテキストを直接編集できます。
  • Validate：保存前にJSON構文をチェックします。
  • Format：JSONを整形（プリティプリント）します。
  • Save（Ctrl+S）：バリデーション後に保存します。
  • Upload：PCからJSONファイルをアップロードします。

旧デスクトップアプリのKPI設定がある場合：

  1. 旧アプリの kpi.json ファイルをテキストエディタで開きます。
  2. JSON内容を全てコピーします。
  3. ナビバーの KPI Settings を開きます。
  4. テキストエリアの内容をクリアし、コピーしたJSONを貼り付けます。
  5. Validate をクリックしてエラーがないか確認します。
  6. Save をクリックして保存します。

または、Upload ボタンで直接.jsonファイルをアップロードすることもできます。

JSON構造リファレンス
{
  "settings": {
    "showAllColumns": true,
    "showAllData": false,
    "maxRows": 5
  },
  "stand": {
    "intervals": [
      {"start": "FP_start", "end": "0m_start", "label": "Time000to625"},
      {"start": "0m_start", "end": "100m", "label": "Time000to100"}
    ],
    "mainKPI": "Time000to100",
    "sortOrder": "asc"
  }
}

  • KPI/設定ファイルを保存・アップロードするたびに、タイムスタンプ付きのバックアップが自動的に作成されます。
  • バックアップは元ファイルと同じディレクトリの backups/ サブフォルダに保存されます。
  • バックアップファイル名には日付と時刻が含まれます：kpi_20260522_170300.json
  • ファイルごとに最大 50 件のバックアップが保持されます。古いバックアップは自動的に削除されます。
  • 以前のバージョンを復元する必要がある場合は、管理者にお問い合わせください。

  • 管理者ログイン：ナビバーの「Admin」をクリックし、管理者パスワードを入力します。
  • ユーザー追加：ユーザー名を入力してAddをクリック。グローバル設定のコピーで新しいプロファイルが作成されます。
  • 有効/無効：削除せずにユーザーアカウントのオン/オフを切り替えます。
  • JSON編集：ユーザーのsettings.jsonやkpi.jsonを直接編集します。
  • KPI一覧：全ユーザーのKPI設定を一覧表示します。
  • ユーザー削除：ユーザーと全設定を完全に削除します。
